Manipulation · RL

Reach around it

A learned policy (lime) and IK + A* (peach) reach for the same target. Tap to set one.

  • 100% reach
  • 1.56 s vs IK 1.82 s
  • touches 6.8% vs IK 0%

From my work Clutterbot (bin localization, FSM control); working on Mega at Griffin Labs.

How it works · numbers

Two SCARA arms from above on one base, sent to the same target. Lime: a small neural network trained offline with evolution strategies to command joint speeds; it sees the obstacle and the analytic IK goal poses, and dodges the obstacle as it goes. Peach: analytic inverse kinematics with a minimum-jerk profile, and A* in configuration space (inset) when the straight move would hit the obstacle. Both obey the same joint speed and acceleration limits. Training script: tools/train_scara.py.

Sonar navigation

Feel the way

An ROV that sees only a noisy sonar fan steers to your goal with a VFH planner. Tap to set a goal.

  • VFH planner
  • sonar only
  • certainty grid

From my work rov-rl-mujoco: an RL controller learning this task in MuJoCo.

How it works · numbers

An ROV sees only a noisy sonar fan. Echoes build a certainty grid (violet), a vector field histogram (ring) marks blocked directions in coral, and the ROV steers into the free gap closest to the goal. This is a VFH planner; the RL version of this task in rov-rl-mujoco is still training.

Tap to set a goal. Drag a pillar to move it. Turn on the cross-current to see what an unmodelled disturbance does.

How it works · numbers

Two followers try to stay 10 m from a beacon that weaves, sweeps and turns, using the same noisy relative position and velocity. Same plant, acceleration limit, beacon path and noise for both. Lime: a Double DQN trained offline. Peach: a proportional controller with tuned gains. Two of the five paths were never used in training. Training script: tools/train_standoff.mjs.

How it works · numbers

A tracker that sees a target's box for 0.8 s has to say where it will be 1.2 s later, and how sure it is. Lime: a small diffusion model draws many possible futures, conditioned on the target class's agility. Peach: the constant-velocity prediction standard trackers use. Synthetic tracks from a 1280 × 720 px, 30° camera; no real imagery. The tracks are toy manoeuvres, not a model of any real platform.
